Project Overview
A Python-based cybersecurity project designed to identify potential phishing indicators in email messages using rule-based analysis.
FEATURES
.Detected suspicious phishing keywords
.Extract URLs from email content
.Checks HTTP and HTTPS usages
.Calculates a heuristic phishing risk score
.Classifies risk as LOW,MEDIUM,or HIGH
.Generates an automated text report
TECHNOLOGIES USED
.Python 3
.Regular Expressions (re)
.Visual Studio Code
SAMPLE RESULTS
. Suspicious keywords:5
.URLs Found:1
.Risk Score:70/100
.Risk Level: HIGH
HOW TO RUN
1. Install python 3.
2. Download the project.
3. Open the project folder in VS Code.
4. Run python.
phishing_analyzer.py.
5. Review the generated
phishing_report.txt file.
DISCLAIMER
This project is for cybersecurity education and awareness. It uses basic heuristic detection and does not provide a confirmed phishing verdict.
